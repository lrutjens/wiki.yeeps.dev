## v2.2.0 - Boss Update

**Features**

- Added Queen Bug Boss Mob
- Added support for boss mobs
- Added support for mobs with weak spots
- Added support for mobs spawning other mobs
- Added support for mobs with shotgun type projectiles
- Added Biting Bat Mob
- Added Biting Bat raids in Suburb biome when players are above a certain height
- Added Egg Sack Mob
- Added Hatchling Mob
- Added Shockwave Mace
- Added ground shockwave effect for when you smash into the ground with the Shockwave Mace
- Added Head Turret
- Added Fly Swatter
- Added Proximity Chat Game Rule
- Added Bat Wing loot item
- Added Purple Crystal loot item
- Added pickup cooldown system to reduce griefing in Wilds
- Added Yeti Spawn Egg on Snow Tech Web
- Added frog NPCs
- Added Dungeon Keys
- Added Dungeon Key Lock
- Added Swarmslayer bundle
- Added Snail Pet
- Added Grub Pet

**Public World**

- Added Lost Frog Kingdom (2 part dungeon with boss fight)
- Added BAM area next to Build Central
- Added more friend navigation signs in key areas

**Changes**

- Added SFX for all potions
- Grapplers can no longer be used on spikes
- Sawblade Traps block light
- Sawblade Traps, Icicle Traps, and Wooden Cannons always deal damage to players (Can be disabled with the Mob Damage Game Rule Sign)
- Dungeons now appear on the World Map
- NPC mobs no longer trigger Mob Death Trackers
- Speed potion makes you slightly faster
- Small potion makes you slightly smaller

**Fixes**

- Fixed mob explosions not always dealing damage
- Fixed cases where you could grab loot through walls
- Fixed High Quality Mic setting not working when switching rooms
- Fixed typo on High Quality Mic setting
- Fixed Giraffe cosmetic tongue
