- Added 4 official biome records
- Added Record Display block
- Added Tape Player block

- Added speakers
- Added Record Broadcaster block
- Added Tape Broadcaster block
- Added 7 audio channel FX blocks: distortion, echo, reverb, filter, speed up, slow down, volume up

- Added Stage Beam block

- Added Frog Leg ingredient
- Added Leg potion

**Public World**

- Added Rave Cave map (5 new buttcoin stashes )
- Added biome theme records to each biome’s tech web
