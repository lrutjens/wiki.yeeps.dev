## v1.30.0 - Infestation Update
**Features**

- Added Exterminator Bundle
- Added mobs system
- Added 4 types of Mobs (Pincer Bug, Boom Bug, Fat Bug, and Spitting Snail)
- Added Mob Spawn Eggs
- Added Mob Beacon
- Added Singleton Mob Spawner
- Added Multi Mob Spawner
- Added Mob Spawn Zone
- Added Survival Game Mode
- Added Mob Barriers
- Added Stuffed Mini Turret
- Added Stuffed Mortar Turret
- Added Stuffed Missile Turret
- Added Stuffed Landmine
- Added Wooden Mortar Turret
- Added Wooden Missile Turret
- Added Wooden Landmine
- Added Wooden Exploding Bomb
- Added Turret Targeter
- Added Healing Gun
- Added Health Packs
- Added Mob Damage Multiplier Game Rule
- Added Mob Death Tracker
- Added Max Performance Mode setting (recommended if you're experiencing extreme lag, but will reduce game graphics quality)

**Public World**

- Added Infested Castle (5 new butt-coin stashes)
- Removed Mushroom Village
- Added Clear Mobs button to Wilds

**Changes**

- Stuffed/Wooden Auto Turrets are now called Stuffed/Wooden Pellet Turrets
- Shield bash does no damage
- Freeze Gloves do less damage when hitting frozen enemies
- Shields/Freeze Gloves cannot be refunded immediately after breaking
- Shields always fully blocks at least 2 hits
- Freeze Gloves always fully block at least 1 hit
- Turrets are quieter when targeting things that aren't you
- Hazmat and Mummy headpieces can be worn with hats
- Poison damage has distinct SFX
- Shortened initial delay on Map Copier and Zone Copier buttons
- Optimizations
- Better performance on blocks and cosmetics when they are far away
- Better performance on wiring when it is far away
- Optimized VFX when they are too far away to see

**Fixes**

- Made selecting blocks near walls with the Zone Copier easier
- Fixed dying repeatedly when in lobby
- Chainsaw rev SFX no longer cuts off if you destroy the item while revving
- Fixed "Twoshrooms" being the only plural mushroom
- Fixed Sound Tap volume spam protection acting on musical machines
