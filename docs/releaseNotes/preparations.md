## v1.31.0 - Preparations Drop
**Public World**

- Hints towards 2.0 on some maps

**Mobile**

- Added "Cinematic Mode" for smoother sweeping shots (best paired with Invisible Controls)

**Changes**

- Pins do damage to mobs
- Added more LODs to things like spikes, game rule signs, props, and ingredients
- "Landmine" is called "Wooden Landmine" for consistency
- Settings button on Player List appears regardless of which controller is disconnected

**Fixes**

- Fixed being able to get tagged in Tech Web
- Fixed Brittle Glass on Tech Web sometimes breaking
- Fixed map loading in the wrong room
- Fixed holding multiple items at once*
- Fixed Drumstick and Boxing Glove getting stuck to hands sometimes
- Fixed Zone Copier message not disappearing when you grab the Zone Copier
- Fixed Damage Multiplier Rule not applying when attacking mobs
- Fixed mobs being able to spawn from eggs when switching rooms
- Fixed bug when drinking potions while switching rooms
- Added limit to Gimbal Camera
- Fixed Creative Mode sound not playing when switching to Creative Mode in Community Worlds
- Fixed mushroom stash sounding like wood when you touch it
- Fixed zipper LODs turning on too soon
- Fixed Wishlist scroll having a stuffing cost
- Fixed issue when putting empty potions in crossbows into things
- Fixed mobs being able to spawn on top of upside down spawners
- Fixed typo with "Max Performance Mode"
