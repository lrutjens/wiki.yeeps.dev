## v1.26.0 - Prop Hunt Update
**Features**

- Added the ability to disguise yourself as any block
- Added Prop Scanner
- Added Prop Hunt Game Mode
- Added 32 prop blocks
- Added Prop Tech Web
- Added No Props Drain Stuffing Game Rule
- Added Achievements system
- Added Achievements Console
- Added Bunny pet
- Added 2x2 wooden door
- Added a setting to always hide banned items
- Props can taunt in Prop Hunt Game Mode (using face buttons)

**Public World**

- Added Prop Town map (5 new butt-coin stashes)
- Added many variants of Prop Town that cycle each round
- Added themed decorations to Starter House, Blue House, and Playground
- Each biome has its own Tech Web/Cosmetics Store color to clarify that they are different

**Changes**

- You (and only you) see an outline of your hands whenever your body becomes invisible
- Reversed the oven wiring input that controls the door open / door closed state
- Increased invincibility duration at the start of rounds
- Changed default color of Game Modes Tech Web

**Fixes**

- Fixed Hungry Hippo sound not going away when it’s done eating
- Fixed Jank Mode rule not working sometimes
- Fixed dagger not having a haptic when hitting blocks/dummies
<br/>
