    v2.0.1 - 2.0 Patch 1

    Changes

    • Quest 3S should run at 90fps like Quest 3 instead of 72fps
    • Saw-blades can now roll outside the map
    • Changed loot type preview in the loot for silver bucket
    • Vacuum can suck items anchored to mobs

    Fixes

    • Fixed small buttons being hard to press (let us know if its fully fixed in ⁠💭・feedback)
    • Fixed game displaying fake bean rewards for mobs causing players to seemingly "lose" beans
    • Fixed pink cube being dupable and causing lag
    • Fixed wierd out of body experience caused with outlines
    • Fix sometimes NPC dialog appears at world origin and stays there
    • Fixed being able to go inside terrain blocks by trigger a map reload
    • Fixed loot sack appearing visually full when it can still accept items
    • Fixed branching only world map nodes being slightly transparent
    • Fixed being able to see the map while fast traveling
    • Fixed chainsaw disappearing when it shouldn't

    v2.0.2 - 2.0 Patch 2

    Features

    • Added daytime ambience

    Changes

    • Fast Travel to Gnome Capital is free
    • Mobs drop more beans on average
    • Loot sells for twice as many beans

    Fixes

    • Fixed buttons mysteriously pressing
    • Hopefully made button pressing more easy and reliable
    • Fixed being able to raise terrain into the lobby or hallways
    • Fixed NPCs spawning in the ground
    • Fixed typos on Community Guidelines
    • Fixed wrist vacuum not working properly when out of stuffing in creative mode
    • Fixed lag when creating ragdolls for players on a team
    • Fixed pet thought bubbles not having color
    • Fixed Techno neck cosmetic having the wrong color
